# Welcome to the Knowledge Base

This is your central place for documentation and knowledge articles. The sidebar on the left is **auto-generated** from the `docs/` folder structure: add new folders and markdown files, and they will appear in the navigation automatically.

## Getting started

- Use the sidebar to browse by topic.
- Each category corresponds to a folder under `docs/`.
- Add a `_category_.json` file in any folder to set its label, position, and collapsed state.

## Adding content

1. Create a new folder under `docs/` for a topic (e.g. `docs/my-topic/`).
2. Add `_category_.json` with a `label` and optional `position` and `collapsed`.
3. Add `.md` files with YAML frontmatter (`title`, `sidebar_position` as needed).

Happy documenting!
