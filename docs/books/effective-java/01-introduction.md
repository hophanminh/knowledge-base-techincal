# 1. Introduction

## Chapter overview

The introduction explains how *Effective Java* is organized and how to use it. The book is built around **items**: short, standalone essays that each state a clear rule and the reasoning behind it. The goal is “effective” Java—code that is correct, readable, maintainable, and robust. The items are grouped into chapters by theme (creating/destroying objects, methods common to all objects, classes and interfaces, generics, enums and annotations, lambdas and streams, methods, general programming, exceptions, concurrency, serialization). You can read the book cover-to-cover or use it as a reference; each item is self-contained enough to look up when you need it.
