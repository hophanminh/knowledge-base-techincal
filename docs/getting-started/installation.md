# Installation

This page describes how to set up the knowledge base and run it locally.

## Prerequisites

- **Node.js** v18 or later

## Steps

1. Clone or download the project.
2. From the project root, run:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

Changes to files under `docs/` will hot-reload in the browser.
