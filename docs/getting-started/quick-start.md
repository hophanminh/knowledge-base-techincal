# Quick Start

A short guide to adding your first article to the knowledge base.

## Create a new article

1. Create or choose a folder under `docs/` (e.g. `docs/my-topic/`).
2. Add a markdown file, for example `my-article.md`.
3. Add frontmatter at the top:

   ```yaml
   ---
   title: My Article
   sidebar_position: 1
   ---
   ```

4. Write your content in Markdown below the frontmatter.

The new page will appear in the sidebar according to the folder structure and `sidebar_position`.
